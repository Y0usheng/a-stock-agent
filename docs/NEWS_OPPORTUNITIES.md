# 从行业新闻到长期模拟研究

默认A股订阅流程现在先发现行业主题，再选择公司。美股新增工作继续暂停。“市场前景”在此阶段指A股行业与主题，不是跨国资产配置。

流程：全局新闻 → 关键词待评价线索 → 一次订阅主题判断 → 受控公司候选 → 原有四角色核对业务、财务与估值 → 独立风控和宿主检查 → 模拟持仓。主题发现与公司研究分别冻结输入、判断和用量。

## 来源和证据

现有 `servers/news_server.py` 增加 `market_discovery_feed` MCP 工具，从东方财富全球财经快讯公开接口一次读取最近200条。接口参数沿用本地AKShare的 `stock_info_global_em` 源码，其中 `req_trace` 是有效请求所需参数。一次连接/读取分别限5/15秒，宿主总等待25秒；没有无限重试、付费新闻依赖或伪造备用数据。个股公司公告/新闻仍走原有工具。

可导入具体HTTPS文章：政府网站（gov.cn及子域名）、巨潮、沪深交易所、东方财富、财联社。导入不代表已验证内容真伪。政策原文、公司披露、媒体报道分别标记；媒体转载原始出处无法确认时统一计为一个未知来源组，不能用转载次数证明多源共识。

`data/opportunities.db` 保存事件ID、内容哈希、原文片段（最多1800字）、文章URL、发布时间、首次采集时间和采集成败；修订生成新身份，不覆盖旧片段。只保存event_id无法保证提供方日后仍能返回当时内容，因此本地保留绑定片段。没有声称已下载公告全文。

进入某行情日研究，发布时间和首次采集时间都必须不晚于该日15:00。收盘后第一次采到的新闻留待下一截面，不回填历史研究。日期未知、正文缺失、内容哈希不符和同日重复标题排除。当前源仅覆盖最近快讯及积累的30日存档，不能宣称全市场或历史完整。

## 判断和候选

关键词仅路由，不打“利好分”。每轮最多3个主题、每主题2篇最新文章；模型每篇最多看到450字，完整本地片段仍保存。评审仍限一次调用、75秒、12,000 tokens；超出主题/文章数量会明确标记为预算延后。模型分别给出：优先研究/观察/风险/否决、结构/周期/短期/不确定、时间范围、现金流传导假设、反方观点、待核验项和失效条件。

v3输出按主题、篇目绑定，每篇新闻只选支持/反证/未使用之一；原始事件ID及来源类型由宿主恢复，仍核验连续原句，不能跨主题引用或把同篇同时放进支持和反证。只给模型事件身份与必要片段，完整URL继续保留本地追溯。接收的原始结构化响应先保存到本机`data/review_receipts/`，通过校验后才进入有效评审缓存。

风险主题也会触发公司暴露核验：宿主从已有受控行业映射选最多2家公司，和优先研究候选共用每轮2家预算。这属于待核实关联，不是模型选出的受益公司，不赋予买卖权限；公司披露、估值、经理及独立风控仍须分别通过。观察、否决、未完成或失败的主题不能通过该路径补造研究优先级。

若新闻阶段已成功但公司研究未完成，可只在该次进程设置`ASTOCK_RESUME_NEWS`为本机已保存快照的完整指纹，然后执行同一正式入口。宿主重新核对快照、连续原句、发布时间与首次采集、评审时点和同一行情日；失败、改写、未来或跨行情日的快照不能续跑。新闻评审时间保持原值，另记恢复时间及原始用量；本次新闻调用与用量为零，公司研究和风控仍真实运行。自动任务不默认开启此选项。

支持/反证ID必须属于当前主题；每项引用必须附模型可见片段中的连续原句，来源类型不能被改写。这个检查证明引用和摘录存在，**不证明推断一定由原文支持**；语义蕴含、行业映射及来源真实性仍需抽查与补证。推断不生成可冒充公司披露的证据ID。

优先研究要求至少12个月、结构或周期判断、有引用；短期噪声不可入选。候选只能来自主题与项目现有12家公司之间的待核验映射。电网、半导体、房地产等有线索而未映射的领域仍显示覆盖缺口，例如不会把水电运营商直接当作输配电设备受益公司。

每轮最多3个新增公司候选，按模型给出的研究优先级排序，同优先级按主题ID/代码作确定性排序，不宣称同档公司存在投资优胜排名。已有持仓保留；无合格新候选或模型失败时延续已有研究，没有已有研究则跳过，不自动回到宁德时代等种子池。界面逐家列出入选、未选、名额外与保留原因。

发现阶段最多1次订阅请求、75秒；12,000 tokens为调用前/完成后检查阈值，单次生成不能硬截在精确令牌数，超限结果拒用并记录实际用量。模型可见输入、指令、结构、模型与设置共同绑定缓存，同输入再次执行不新增发现请求。原有公司四角色另外最多4次/40,000 tokens。分页和网页展示不调用模型。

行业主题只作为前序模型假设进入长期角色。建仓仍须可用的公司业务/财务披露、估值、仓位与价格检查；现阶段披露片段需经 `company_research.py` 导入，尚未自动取得全文。没有新新闻不重置已有论证。`--research-symbols` 固定研究实验绕过发现流程，以保留对照口径。

## 运行与观察

```powershell
# 只采集和路由，零模型调用，不选出新候选
.venv\Scripts\python scripts/discover_opportunities.py --refresh --rules-only

# 对已存档资料进行一次主题判断；不触发公司研究或下单
.venv\Scripts\python scripts/discover_opportunities.py

# 完整A股流程，只分析；行情日的时间过滤依然生效
.venv\Scripts\python agent/run_daily.py --market cn --shadow

# 更新候选真实曲线，默认也保留过去入选公司的观察
.venv\Scripts\python scripts/refresh_trading_view.py --provider sina
```

独立发现命令的 `--as-of` 是研究规划日，可在收盘前准备资料；它没有行情成交能力。正式日循环以真实已收盘行情日为截止，不会使用规划日的未来知识。导入文件是事件数组，每项含 `title/excerpt/url/published_at`，首次采集时间由宿主生成，不能在文件中伪造。

`/trading` 展示主题、原文、模型假设、候选理由及真实股价；`/api/opportunities` 是只读发现快照。无股价缓存时也可看到主题。入选后的观察从严格晚于入选日的第一个已收盘价格开始，至少两个后续价格才能计算涨跌；未计交易费、未模拟成交，不能计入账户收益。真实模拟收益仍只按实际账本成交计算。旧版5日实验和新252日阶段观察保持原协议，不事后改写。

运行数据库、原始新闻、账户日志和HTML导出保存在本机，不随代码上传GitHub。尚无足够向前持仓期，不能由流程测试或空仓零亏损得出投资能力结论。
