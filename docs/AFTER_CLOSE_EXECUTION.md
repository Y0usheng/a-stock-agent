# 收盘后研究、原始公告与未来模拟成交

默认长期版本为 `manager-long-v3`，使用 `after-close-next-session-v1` 时间协议，并在独立风控通过后自动排定模拟计划。旧v1/v2与既有实验日志保留原始含义，不将新材料回填为旧实验已知资料。[自主模拟与策略学习](AUTONOMOUS_PAPER_LEARNING.md)说明新默认行为。

技术角色使用宿主计算的真实收盘、均线与RSI事实快照，明确标记零模型调用；基本面、投资经理、独立风控分别调用模型。新流程不把计算指标包装成第二份独立模型意见，通常用3次公司研究调用完成；预算上限仍为4次和40,000 tokens，超限或用量不完整的结果不得当成已通过实验。

为使两家公司研究留在同一预算，v3模型输入每家公司仅选最新业务及最新财务各一份原文片段。业务仅展示前400字并标记截断；财务选段和单位保持原文，不从标题推断。旧期及完整PDF、页码和哈希继续留本机，输入明确说明未展示范围。URL等重复来源元数据保留宿主目录，模型使用证据ID；经理价格历史只展示5个等距月度样本并标明采样。模型自由文本字段限160字，原有数值及引用校验不变；独立风控仍核对原始可见材料，而非只读分析师总结。若剩余额度连已观察的基本面输入成本都不足，不再启动风控调用，也不批准计划。

每股公司新闻只展示最新1条，完整采集仍留本机，行业风险假设另行保留。零成熟样本时只发送学习状态与数量，不重复发送空指标、空评估和空结果列表；原始学习快照不变。

## 一次日循环

工作日17:30的本机任务先处理此前已确认、已到执行日的计划，然后研究新机会。新的公司研究最多新增2家，已有持仓继续复核。流程区分以下时间：

| 时间 | 用途 |
|---|---|
| 行情日15:00 | 最新已完成交易日的价格参考；不同公司日期不一致或落后于最近已收盘交易日时停止 |
| 实际信息截止 | 在模型调用前冻结；新闻与公告须在此之前发布并已被观察 |
| 决策完成 | 四角色完成、宿主验证后的实际时间 |
| 确认期限 | 执行交易日14:55；逾期不能事后挑选收盘结果 |
| 执行日15:00 | 事先确定的未来收盘价模拟时点；日历无覆盖时停止，不按星期猜节假日 |

例如10月29日盘后形成的计划，最早安排真实日历中的下一交易日收盘。10月29日已经知道的收盘价只作参考，不登记成当日买入。确认不调用模型，也不立即成交；下一次本机运行读取指定执行日的原始收盘价，核验后才写入账本。

## AI自主模拟与旧版本确认

正式入口仍为：

```powershell
.venv\Scripts\python agent/run_daily.py --market cn
# 新默认版本无需逐笔确认。下面仅用于既有v2待确认计划：
.venv\Scripts\python agent/run_daily.py --market cn --approve-plan <完整计划哈希>
# 取消未完成的计划：
.venv\Scripts\python agent/run_daily.py --market cn --reject-plan <完整计划哈希>
```

计划固定股票、方向、数量、账户基础状态、独立风控结果、信息截止与执行日。已确认计划的撤销也须在14:55之前，不能看过收盘结果再选择取消；因账户变化被冻结的不可执行计划可取消剩余部分。买价含滑点后不得高于参考价102%，卖价不得低于98%。超限或无法判断的全天单一价格取消；不会调整数量、改用其他日期或再次请模型追价。账户发生计划外变化会冻结计划。真实报价暂不可用时保留待恢复状态，阻止新计划覆盖。

成交沿用原生模拟账户的费用、T+1、手数、仓位和成交量约束。执行行情为指定交易日的不复权价格，研究历史可用前复权数据；两者分别标识。稳定订单身份与账本对账支持“已成交但进程中断”的恢复，避免重复扣款。计划事件保留生效时间与记录时间，旧日期报告不会显示之后才批准的状态。

本模式是预先确认的收盘价模拟，包含事后日成交量检查，不模拟真实收盘集合竞价排队或可成交保证。生产账本只记录真正执行的模拟计划；测试用临时账本不会写进真实实验收益。

## 自动获取原始公告

每家公司从巨潮官方索引选取最新完整年报和其后最新季报/半年报，排除摘要、英文版及更正说明等不完整条目。仅允许受控HTTPS来源；限制大小、重定向、页数与总时间。每轮最多2家公司、90秒，不调用模型下载或提取。可单独补证：

```powershell
.venv\Scripts\python scripts/collect_disclosures.py --symbols 601138 300308 --budget-seconds 90
```

原件位于被Git忽略的 `data/disclosures/`，按PDF内容SHA-256命名；索引、首次下载、逐页文本及文本哈希一并留本机。自动选择业务与主要财务页，片段保存PDF页序、文本位置及多页来源。PDF页序可能不同于印刷页码。财务单位必须属于当前表；表头在上一页时，只有严格匹配续表才能拼接。无单位的财务片段不能在新协议中充当可用交易依据。单位与金额不从公告标题猜测。

报告期未经文本核验时保持空值；索引只有日期时按当日日末可用，不能伪造披露小时。提取仍标记 `source_truth_verified=false`：保存全文、单位定位和引用校验不等于独立语义审查。扫描件、代码绑定失败、提取超时或来源不可用均保留补证缺口。

## 公开展示与验收

公开报告只展示必要时间、未来计划状态、判断摘要与真实曲线，不上传原始公告、模型输入、数据库、确认哈希或登录凭据。按决策实际时间归档；新研究不能回填到更早的行情日期。即使后续研究失败，发布步骤仍可展示本轮已经合法登记的既有计划成交，并保留分析失败状态。

新增回归覆盖真实交易日历中的假期、收盘前不执行、逾期确认、价格偏离取消、账户变化、复权报价拒绝、成交后中断恢复、盘后信息可见性和跨页单位。原有凭据扫描、公开归档与风控回归继续运行。真实来源试验与生产收益分开记账，不用测试成交证明投资能力。

本次实际试验及仍未通过的真实模型环节见[验收记录](AFTER_CLOSE_ACCEPTANCE.md)。模型单次120秒限时保持不变，整个收盘处理等待默认限额600秒；清理连接和进程可能额外耗时。预算检查拒绝超限结果，但不等于供应商侧硬性消费上限。
