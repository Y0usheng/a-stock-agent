## 1. 证据追溯（默认订阅流程基础版已实现）

2026-10-27 已接入冻结证据目录、逐条专家结论/决策/预测/风控引用、支持/反证/失效条件、宿主 ID/内容/股票/时间校验，以及新闻 MCP 的事件回查；当时135项测试通过。随后已增加A股离线语义核验和向前研究首次可见时间约束；公告正文自动补充与人工标注校准仍待完成。来源选择、边界和真实采集样本见 [证据追溯说明](EVIDENCE_TRACEABILITY.md)。

把当前新闻存储、内容哈希和冻结输入扩展为逐条结论的证据链：

- 证据保存来源、原文链接、发布时间、实际采集时间、内容哈希及数据质量。
- 分清事件发生、信息发布、系统首次看到的时间；历史重放声明采用何种可见性口径。
- 分析结论引用稳定的证据 ID，并记录支持因素、反证和失效条件。价格与基本面证据也绑定具体截面及字段。
- 宿主核验引用是否存在、是否属于本轮输入、是否在截止时间前可用。引用有效不等于原文必然支持结论，后者另行抽样评估。
- 来源缺失、合成事件、未知时间或无法核对的引用明确标记；禁止用这类结果宣称真实历史效果。

验收：构造未来新闻、缺失来源、伪造证据 ID 和内容变化的案例，确认日志能区分并拒绝无效引用；从一条预测能回溯到当时使用的数据。

## 2. 实验闭环（基础版已实现）

2026-10-27 已实现研究登记、固定股票池/对照/标准、不可改写输入、三阶段到期评分、同成本组合重放、失败与无数据留存、固定候选复盘、下一轮建议及父子研究。177项全量测试通过；合成工程与真实历史价格分别跑通9次尝试和原样重放。真实价格技术候选低于固定基线，按标准否决；历史新闻不足的变体保留无数据。入口、报告与边界见 [实验闭环说明](RESEARCH_LOOP.md)。

在已有实验注册表、同截面比较、到期评分和校准基础上，增加可追踪的研究任务：

`假设 → 固定数据与评价标准 → 运行变体 → 样本外评估 → 保留或否决 → 下一次假设`

- 在实验前保存假设、目标市场、股票池、预测期限、对照组和成功条件。
- 比较买入持有、简单技术策略、新闻门控和模型分析；使用相同输入、成交假设和费用口径。
- 分开记录方向预测、组合净收益和研究效率；只分析日志不生成虚构的账户收益。
- 按时间隔离训练、调参验证和最终测试；记录尝试次数，避免不断挑选偶然胜出的变体。
- 自动复盘汇总成熟预测、净收益、回撤、交易成本、调用用量、数据问题和证据缺口；样本不足时保持未验证状态。
- 自动提出下一次研究建议；策略进入模拟运行仍需通过既有宿主约束，不能由研究 Agent 自行修改风控规则。

验收：完整重放一项研究的假设、数据指纹、配置、结果和复盘；变更数据或评价口径后不再直接比较；失败和无数据的运行保留记录。
