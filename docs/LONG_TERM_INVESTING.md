# 长期投资协议与研究底稿

更新：2026-10-29。A股订阅LangGraph默认版本改为 `manager-long-v1`；原始5日日志和 `manager-v1/v2` 保留。默认命令只运行A股，美股须显式指定，本阶段继续暂停新增美股工作。

## 改动目标

避免把“资料不足→一直观望→账面没亏钱”误当成投资能力。默认采用三年投资论证、一年252交易日阶段观察和最长90天复核期限。三年是论证观察框架，不是到期自动卖出或承诺持有三年；一年方向预测不再充当每日交易开关。

默认改为[新闻主题发现研究池](NEWS_OPPORTUNITIES.md)：先判断行业机会，再从受控公司映射中选出最多3家新增研究对象，并保留已有模拟持仓；原固定三股票配置仅作行情截面探针，不代表入选。没有新合格主题时延续已有研究；`--research-symbols` 可在shadow验收中固定受控范围。公司研究的新闻窗口为30天，监控投资论证变化；没有新新闻不会自动否决已有论证。真实价格、现金、整手/T+1、独立风控和宿主仓位上限继续校验。

## 输出不再只有HOLD

每只股票新增 `investment_cases`，保存三年论证、研究状态、估值方法/假设及悲观/基准/乐观价格、目标仓位、建仓/退出条件、核心/辅助缺口、下次复核日期和引用。

| 持仓意图 | 含义 |
|---|---|
| research_pending | 核心研究尚未完成；须有具体补证任务 |
| wait_price | 研究及估值可用，但当前尚不满足建仓条件 |
| build | 提出建仓计划，仍须经独立风控及既有执行约束 |
| hold | 已有投资逻辑延续，继续持有 |
| reduce / exit | 减仓或退出；有据的风险退出不会被“增长资料尚不完整”阻止 |

核心资料包括业务与财务原文依据及估值论证。缺少某个辅助指标或没有新新闻，可以列入 `non_core_gaps`，不一概否决。建仓和估值等待都必须引用可用的业务/财务披露记录；只有价格指标不能冒充长期基本面研究。送审股数须符合目标仓位，不能把估值目标价填作当前成交价。

研究未完成须在7天内复核。任务首次期限不会随着每日分析向后重置；逾期会显式标记。复核期限目前是记录和展示，不是后台定时任务。

## 研究材料与记忆

`data/company_research.db` 保存材料、首次论证和任务。材料仅接受受控HTTPS披露来源：巨潮、上交所、深交所及其子域名；保存披露时间、报告期、页码/段落、片段、首次导入时刻和内容身份。默认400日有效，最长550日，过期需要更新；多年前数据可随最新年报中的历史比较表提供。

业务、财务、行业材料按类别优先选取，避免近期财务片段挤掉业务原文。模型每股票最多读取4份材料的有限片段；截断会标记，不能假定已读完全文或脚注。导入记录不等于已独立确认原文真实性或数字语义，当前还没有自动下载并核对全文的采集器。

上次投资论证只作为“过去模型观点”输入，不冒充外部事实。按模型、Prompt与推理配置分开留存；同版本同日首次输出不可覆盖。旧论证只在其日期之后读取，新闻不再使底稿每天从零开始。现阶段每次显式运行仍执行四角色，尚未实现“无变化时自动跳过模型”的省调用调度。

长周期价格输入优先复用有指纹的本地真实缓存，否则限时请求历史；传入历史采样、近期日线、观察数量及完整历史哈希。未来日线被截掉，历史末日价格与冻结快照不一致时不向模型提供。历史不足两年标为辅助缺口，不能把180日数据声称为三年完整价格。

## 使用入口

```powershell
# 默认A股、订阅、长期版本；此命令会调用模型，但不下单
.venv\Scripts\python agent/run_daily.py --market cn --shadow

# 单股票真实资料验收
.venv\Scripts\python agent/run_daily.py --market cn --shadow --research-symbols 300750

# 显式回到旧协议复现；ASTOCK_PROMPT_VERSION环境配置仍可覆盖默认版本
.venv\Scripts\python agent/run_daily.py --market cn --shadow --prompt-version manager-v1

# 以下操作不调用模型
.venv\Scripts\python scripts/company_research.py tasks
.venv\Scripts\python scripts/company_research.py snapshot --symbols 300750 --day 2026-10-28
.venv\Scripts\python scripts/company_research.py import-material checked_material.json
.venv\Scripts\python scripts/company_research.py prepare logs/live/2026-10-28.cn/frozen-input.json --output logs/live/2026-10-28.cn/long-term-prepared.json
.venv\Scripts\python scripts/evaluate_investment.py
```

材料文件为一个对象或对象数组，字段为：`symbol`、`title`、真实受控 `url`、实际 `published_at`、`report_period`、`categories`（business/financials/industry）、`excerpt` 和 `locator`；可指定 `expires_at`。片段须保留表头、单位、限定条件，不能用报告期替代披露日期。只导入已经核对的片段，不填占位文字。

CLI `prepare` 仅准备已有资料，明确标记 `preparation_only`，不生成新模型判断或买卖。新的长期模式仅实现于A股订阅LangGraph；API/SDK对照与规则替身继续显式使用旧协议。默认执行模式没有改成自动模拟下单。

## 评价与展示

一年方向评分与实际组合表现分开。长期输出不能被登记到原先固定5日的研究计划；`evaluate_investment.py` 单独输出252日到期状态、实际模拟组合、当前现金占比，以及分析时空仓相对观察股票涨跌的机会成本示意。尚未到期或全程现金0收益不会自动判策略成功。机会成本示意不含交易费用，不是账户收益归因。

语义核验增加投资论证、建仓/退出条件和估值假设，原文引用可定位到所保存的片段。图表页增加长期论证和补证任务；未重新运行模型时，原有5日判断明确标为旧版短期参考。

## 本次验收和边界

206项测试通过，含18项长期专项：无新新闻仍可提出有据建仓；缺核心材料不能冒充研究完成；辅助缺口不自动否决；仓位/估值/冻结价检查；风控拒绝后保留原提议与实际动作区分；材料复用/到期；任务期限不后移；一年预测未成熟不评分；原生四角色本地替身完整运行。

真实已有资料已准备为 `logs/live/2026-10-28.cn/long-term-prepared.json`：宁德时代180日历史可用，受控公司披露片段尚为0，已建立业务与财务两项补证任务，期限2026-11-04。保留10月28日的首次旧版输出，没有生成新的长期模型结论，也没有新订单或新增模型请求。

下一项数据工作是取得并核对多年年报/最新季报中的业务、现金流和负债片段，然后以新协议运行实际模型。当前代码通过并不证明长期投资有超额收益，也不会为了增加交易而强迫建仓。
