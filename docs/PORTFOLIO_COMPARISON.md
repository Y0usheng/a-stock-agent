# 组合基准与空仓对照

组合是否值得持有，不能只看绝对盈亏。本页从事前登记的同一起点，对照实际模拟账本、沪深300全收益指数和不计利息的现金本金。空仓时市场上涨会留下机会差；市场下跌可展示避开的参考跌幅，两者都不记作实际成交利润，也不会据此强制买入。

## 固定口径与时间

- 市场对照固定为中证指数公司的沪深300全收益指数 H00300，含税前现金分红再投资，不扣交易或管理费用。它是理论指数，不是ETF成交回报。来源：[指数资料](https://www.csindex.com.cn/zh-CN/indices/index-detail/H00300)、[指数计算规则](https://oss-ch.csindex.com.cn/contract/cms_add/20240726155028-%E3%80%8A%E4%B8%AD%E8%AF%81%E6%8C%87%E6%95%B0%E6%9C%89%E9%99%90%E5%85%AC%E5%8F%B8%E8%82%A1%E7%A5%A8%E6%8C%87%E6%95%B0%E8%AE%A1%E7%AE%97%E8%A7%84%E5%88%99%E3%80%8B.pdf)。
- 首次显式刷新在本机写入不可覆盖的登记：固定规则、真实登记时间、真实交易日历身份，以及严格晚于登记时间的首个收盘。无事前登记的旧报告不补填基准成绩。
- 账户和指数均从该收盘点归零。只有一个点时不评价策略表现。相对指数差用百分点表示；现金机会差用起点资产乘同期指数涨跌表示。
- 平均现金比例是已记录收盘估值点现金比例的算术平均，不是盘中或时间加权风险指标。
- 首个登记收盘之后的每日成对估值只追加、不重写。原始价/NAV/成交记录变更、区间缺口、指纹不符均停止完整比较；不悄悄把起点滚动到更有利日期。历史报告按观测实际写入时间隔离未来信息。

## 当前账户权益边界

已增加[独立权益核算](CORPORATE_ACTIONS.md)：未复权价格加应收/到账的税前分红及送转权益。持仓区间的每个估值点均须通过来源覆盖、原始价格及账本核对，才能恢复相对基准评分；此前未通过的估值不追改成已核验成绩。来源不全、事项不支持或旧估值变化时继续暂停评分。账户未模拟个人股息差别税，指数也不计交易费，两者口径在页面说明。现金机会差金额仅在全程空仓时显示。

## 刷新和发布

```powershell
# 需要真实交易日历、官方指数来源和本机行情/账本；零模型调用、零订单
.venv\Scripts\python scripts/refresh_portfolio_comparison.py
```

日常 `scripts/run_scheduled.ps1 -Paper -Publish` 在股价刷新后执行此步骤，再导出白名单报告。登记后的首个收盘尚未到达时是正常等待，不展示虚构的零收益线。起点已过但缺少组合价格、指数未更新、对账失败或旧记录被修订时返回失败，保留已登记起点和已存估值；发布真实缺数状态，不重新调用模型。恢复后重试这个刷新命令，再导出和上传报告；若只是上传失败，只重试已有公开报告上传。

本机文件位于被Git忽略的 `data/portfolio_comparison/`：`policy.json` 登记、`index.json` 官方收盘缓存、`observations.json` 成对估值、`status.json` 刷新状态历史。页面读取不写这些记录；公开报告仅导出经过白名单与凭据检查的摘要和收益序列，不含原始账本、成交指纹或本机目录。
